# Codex Prompt - Research to Engineering Spec

Read:

- `references/notes/research-summary.md`
- `references/notes/source-by-source.md`
- `references/notes/algorithm-candidates.md`
- the current pixelization implementation and tests

Do not modify production code yet.

Convert the research into an engineering proposal for this repository.

Create or update:

- `specs/pixelization-research-spec.md`
- `specs/visual-quality-test-plan.md`

The engineering spec must contain:

1. Current behavior
2. Problems or limitations identified
3. Research-backed opportunities
4. Proposed algorithms / approaches
5. Rejected or deferred approaches and why
6. Configuration/API changes, if any
7. Backward-compatibility risks
8. Performance risks
9. Acceptance criteria
10. Required tests

For every proposed change, label it as one of:

- SOURCE-BACKED
- ENGINEERING-INFERENCE
- EXPERIMENTAL

Do not claim that a source proves a recommendation when the recommendation is actually an inference.

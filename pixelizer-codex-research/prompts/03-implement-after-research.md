# Codex Prompt - Implement After Research

Read the applicable instructions in `AGENTS.md`, then read:

- `specs/pixelization-research-spec.md`
- `specs/visual-quality-test-plan.md`
- relevant files under `references/notes/`

Inspect the current implementation and tests.

Implement only the changes that are sufficiently specified and testable.

Before editing, briefly state:

- which files you expect to change,
- which observable behaviors may change,
- which regressions are most likely.

Then:

1. implement the smallest coherent change,
2. add/update automated tests,
3. add reference-image or fixture tests when useful,
4. run the relevant test suite,
5. report any behavior that still needs visual/manual validation.

Do not silently expand scope beyond the research spec.
If a research idea remains uncertain, leave it unimplemented and record it as a follow-up experiment instead.

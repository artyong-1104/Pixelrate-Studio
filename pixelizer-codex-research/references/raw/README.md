# Local Source Snapshots

Use this directory only when Codex cannot reliably open an original research URL.

Suggested naming:

- `source-01.html`
- `source-02.html`
- ...
- `source-08.html`

If a page depends heavily on images, also save the relevant images in a matching directory, for example:

`source-01-assets/`

The original URL remains canonical and is stored in `../urls.md`.
A snapshot is only a fallback copy for reproducible research.

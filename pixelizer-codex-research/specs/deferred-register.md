# Pixelate Studio 보류 항목 등록부

보류 항목은 가치가 없다는 뜻이 아니라, 현재 제품 목표와 검증 근거로는 구현 순서를 정할 수 없다는 뜻이다. 아래 재진입 조건이 충족되기 전에는 구현 명세로 승격하지 않는다.

## DEF-001 — 자동 배경 제거와 범용 크로마 키

- 상태: `DEFERRED`
- 근거: Source 02는 RGB 거리 키가 검은 외곽선·배경 혼합색에서 실패하고, 캐릭터 의상과 키 색 충돌도 보고했다.
- 보류 이유: 키 색 선택, 색 언믹싱, 경계 밴드, soft alpha, 의상 충돌을 별도 제품으로 검증해야 한다.
- 재진입 조건: 최소 30개 RGBA/불투명 배경 fixture와 정답 mask, silhouette IoU·fringe·색 오염 지표, 사용자가 배경 제거를 반복적으로 요구한다는 증거.
- 권장 모델: Sol xhigh. 색 언믹싱까지 포함하면 Sol max 검토.

## DEF-002 — 자유 node graph와 stage reorder

- 상태: `DEFERRED`
- 근거: Source 06의 비교 제품은 node 기반이지만 품질·사용성 우위를 입증하지 않는다.
- 보류 이유: 현재 단일 파이프라인의 설정 조합, 접근성, 저장 호환성, 테스트 범위를 급격히 늘린다.
- 재진입 조건: 세 개 이상의 반복 워크플로에서 고정 stage 순서가 실제 blocker임을 확인하고, versioned graph schema와 cycle 방지 규칙을 먼저 승인.
- 권장 모델: Sol xhigh.

## DEF-003 — 비디오 입력, GIF 분해·출력

- 상태: `DEFERRED`
- 근거: Source 06의 제품 기능 사례만 있고 현재 앱은 프레임별 입력을 명시적으로 요구한다.
- 보류 이유: 디코더, 프레임 시간, 메모리 상한, GIF 색상·알파 제한, 취소 UX가 별도 범위다.
- 재진입 조건: ANI-001 완료, 40프레임 제한 안의 메모리 예산, 브라우저별 코덱 지원표, GIF 팔레트 손실 테스트.
- 권장 모델: Sol xhigh.

## DEF-004 — AI 생성·LoRA·PAG 통합

- 상태: `DEFERRED`
- 근거: Source 01·04·07·08은 생성보다 후처리·수동 리터칭의 필요성을 보여 주며 특정 LoRA 수치는 사례 종속이다.
- 보류 이유: GPU·모델 라이선스·비결정성·네트워크 없는 로컬 도구라는 현재 제품 원칙과 충돌한다.
- 재진입 조건: 제품이 로컬 후처리 전용이라는 경계를 변경하는 별도 제품 결정과 모델 라이선스·비용·개인정보 검토.
- 권장 모델: Sol max와 별도 법률·제품 검토.

## DEF-005 — material-aware palette ramp

- 상태: `DEFERRED`
- 근거: 연구에서 팔레트 독식 문제는 확인했지만 자동 재질 분할 방식은 제시되지 않았다.
- 보류 이유: segmentation 없이 재질을 추정하면 불안정하고 PAL-002보다 먼저 구현할 이유가 없다.
- 재진입 조건: PAL-002에서 image-balanced/reference 방식이 실패한 구체적 corpus와 재질별 정답 label 확보.
- 권장 모델: Sol xhigh.

## DEF-006 — 자동 foot-anchor 이동

- 상태: `DEFERRED`
- 근거: Source 01의 연결 모델 카드는 발 정렬을 후처리에 사용하지만 자동 이동이 원래 모션을 훼손할 수 있다.
- 보류 이유: ANI-001의 검수 UX 없이 자동 좌표 변경을 먼저 넣을 수 없다.
- 재진입 조건: ANI-001 완료, 사용자가 지정한 anchor와 프레임별 오차 overlay, 이동 전후 비교 및 되돌리기 명세.
- 권장 모델: Luna xhigh 구현 + Sol xhigh 검토.

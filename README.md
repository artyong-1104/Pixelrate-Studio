# Pixelate Studio

브라우저 안에서 이미지를 픽셀아트 스프라이트로 변환하는 정적 웹 도구입니다. 업로드한 이미지는 애플리케이션 코드에 의해 서버로 전송되지 않습니다.

## 실행

로컬에서는 프로젝트 디렉터리에서 정적 HTTP 서버를 실행해 확인하는 것을 권장합니다. 웹에 배포할 때는 HTTPS와 [SECURITY.md](./SECURITY.md)의 응답 헤더를 적용하세요.

Vercel 배포에서는 `vercel.json`이 루트 `/`를 앱 HTML로 연결하고 같은 보안 헤더를 적용합니다.

## 개인정보 저장

- 이미지 처리와 ZIP 생성은 브라우저에서 수행됩니다.
- 작업 기록 저장은 기본적으로 꺼져 있습니다.
- 사용자가 환경설정에서 기록 저장을 켜면 파일명, 변환 설정, 결과 이미지가 해당 브라우저의 IndexedDB에 저장됩니다.
- JSZip 3.10.1과 화면 글꼴은 `vendor/`에 고정되어 있으며 실행 중 외부 CDN을 호출하지 않습니다.

## 보안 검사

```sh
node scripts/security-check.mjs
```

검사는 CSP 해시와 JSZip 무결성, 위험한 DOM 삽입, 외부 통신 API, 이미지 입력 제한, 작업 기록의 명시적 동의를 확인합니다.

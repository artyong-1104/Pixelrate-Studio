# Pixelate Studio

고해상도 이미지를 픽셀아트 스프라이트로 변환하는 브라우저 도구입니다. 별도 설치가 필요 없으며 이미지 처리는 사용 중인 브라우저 안에서 이루어집니다.

변경 내역: [한국어](./CHANGELOG.ko.md) · [English](./CHANGELOG.md)

## 빠른 사용법

1. **이미지 업로드** 영역을 클릭하거나 이미지 파일을 끌어다 놓습니다.
   - PNG, JPEG, WebP, GIF, BMP, AVIF를 지원합니다.
   - 여러 장을 올리면 숫자를 인식하는 파일명 오름차순으로 처리됩니다. 같은 이름의 파일은 업로드한 순서를 유지합니다. 애니메이션 프레임이라면 `frame_001.png`, `frame_002.png`처럼 이름을 정리해 두는 것이 좋습니다.
   - GIF 애니메이션을 여러 프레임으로 자동 분리하지는 않습니다. 프레임별 변환이 필요하면 각 프레임을 별도 이미지로 준비하세요.
2. **설정 패널**에서 원하는 옵션을 조정합니다.
   - **프리셋 및 설정 관리**: 상단 툴바에서 `기본값`, `애니메이션 안전`, `시트 규격 유지` 프리셋을 선택하고 [적용]을 누르면 변경될 항목 목록(diff)을 확인한 뒤 안전하게 적용할 수 있습니다. [설정 내보내기]로 변환 조건만 담긴 versioned JSON(`pixelate-studio-settings-v1.json`)을 다운로드하거나 [설정 불러오기](최대 64KB)로 다른 브라우저에서 동일한 설정을 복원할 수 있습니다.
   - **크기 처리**: `정사각 다운스케일`은 기존 정사각 변환 방식이고, `정수 배율 축소 (비율 유지)`는 2~16배 정수 배율로 축소하여 원본의 종횡비를 보존한 네이티브 논리 해상도를 출력합니다(전체 이미지 또는 스프라이트 시트 프레임별 분할 지원). 실험 모드 `AI 픽셀 격자 복구`는 alpha-masked Sobel 분석으로 2~32px 격자의 X/Y 주기와 offset을 제안하며, 신뢰도 75% 이상인 결과만 사용자가 직접 적용할 수 있습니다. 낮은 신뢰도 입력은 수동 값 잠금으로 보정하고, 다중 파일·시트에는 한 격자를 모든 프레임에 고정합니다. `원본 규격 유지`는 스프라이트 시트의 원본 캔버스 크기를 유지하며 블록 단위로 처리하고, `크기 변환 없음`은 원본 캔버스에서 색상·정리·외곽선만 적용합니다. 이미지 크기가 지정된 배율 또는 프레임 크기로 나누어떨어지지 않으면 계산 오류가 표시됩니다.
   - **색상 및 팔레트**: `팔레트 방식`에서 `자동 생성 (K-means)`, `직접 지정 (Custom Palette)`, `제한 없음 (원본 색상)` 중 선택할 수 있습니다. `직접 지정` 모드에서는 텍스트 입력창에 `#RRGGBB` 16진수 코드를 입력하거나 `.txt`, `.gpl`(GIMP Palette), `.png` 팔레트 이미지(불투명 픽셀 추출, 최대 1MB)를 업로드하여 고정 팔레트(2~256색)를 적용할 수 있습니다. 중복 색상 자동 제거, 실시간 색상 칩(chip) 미리보기, 미사용 색상을 보존하는 JSON 메타데이터 출력을 지원합니다.
   - **노이즈 필터**: 고립된 픽셀의 정리 강도를 조절합니다.
   - **외곽선 효과**: 굵기, 색상, 4방향 또는 8방향 외곽선을 설정합니다.
   - **내보내기 설정**: 기본 native 해상도 외에 2×, 4×, 8× 최근접 이웃(nearest) 확대본을 추가로 내보낼 수 있습니다.
3. **변환 실행**을 누릅니다. 설정을 처음 상태로 되돌리려면 **조건 초기화**를 사용합니다.
4. **변환 결과**에서 결과 이미지를 눌러 확대 모달을 엽니다.
   - **빠른 배율**: 줌 슬라이더 앞의 `1×`(실제 픽셀 크기), `2×`, `8×`(진단) 퀵 버튼으로 원하는 배율로 즉시 전환할 수 있습니다.
   - **원본/결과 비교**: 상단의 `결과`, `원본`, `나란히` 버튼으로 원본 고해상도 이미지와 픽셀아트 결과를 왜곡 없이 같은 프레임에서 나란히(side-by-side) 비교할 수 있습니다. (저장된 작업 로그에서 복원한 결과는 원본 이미지가 없으므로 결과 보기만 지원됩니다.)
   - **배경 순환 및 알파 진단**: `배경 (B)` 버튼 또는 `B` 단축키로 회색 격자, 흰색, 검은색, 고채도 녹색(`#00FF00`), 마젠타(`#FF00FF`), 시안(`#00FFFF`), 사용자 지정 색상을 즉시 순환하여 잔여 픽셀을 검수할 수 있습니다. 결과 카드에 부분 알파 및 작은 고립 섬 개수가 요약 표시되며, 모달의 `알파 진단` 토글로 고립 섬 위치를 반투명 노란색 오버레이로 확인할 수 있습니다.
   - **애니메이션 검수**: 결과가 2개 이상이거나 스프라이트 시트 변환 결과가 있을 때 결과 툴바의 `애니메이션 검수` 버튼을 통해 검수 모달을 엽니다. 다중 파일 시퀀스(파일명 오름차순, 같은 이름은 업로드 순서 유지) 및 시트 프레임 분할(row-major, 최대 256프레임)을 1~30 FPS 속도, 루프 재생, 1×/2×/8× 퀵 줌, `Space`(재생/정지) 및 `←`/`→`(프레임 이동) 단축키로 검수할 수 있으며, 선택한 결과에 맞는 공유 팔레트·격자 잠금·디더링 정책 칩을 제공합니다. 시트가 256프레임을 초과하면 초과 이유를 표시하고 재생·프레임 이동·FPS·뷰 제어와 관련 단축키를 비활성화합니다. 정상 소스와 초과 시트가 섞여 있을 때도 제외된 시트는 비활성 옵션에 제한 사유를 포함하고, 모달 아래의 경고문도 계속 표시합니다.
   - **PNG**: 변환된 기본 native 이미지를 저장합니다. 선택한 배율이 있으면 `2× PNG` 등의 버튼으로 확대본을 개별 저장할 수 있습니다.
   - **JSON**: 이미지 크기, 팔레트, 픽셀 그리드, 알파 진단 통계 및 내보내기 정보를 저장합니다.
   - **전체 ZIP 다운로드**: 모든 PNG, 선택된 확대본 PNG, JSON을 하나의 ZIP 파일로 순차 압축하여 저장합니다.
5. 필요할 때만 **환경설정**을 사용합니다.
   - 미리보기 배경을 회색 격자, 흰색, 검은색, 고채도 색상 및 직접 지정 색상 중에서 선택할 수 있습니다.
   - **작업 기록을 이 브라우저에 저장**을 켜면 **작업 로그**에서 이전 설정과 결과를 불러올 수 있습니다.

도움말 `?` 버튼은 마우스를 올려 둔 동안 설명을 표시하며, 키보드의 `Tab` 포커스로도 확인할 수 있습니다.

## 알아두기

- 업로드한 이미지는 애플리케이션 서버로 전송되지 않습니다.
- 한 번에 최대 40개, 파일당 최대 20MB, 전체 최대 80MB까지 업로드할 수 있습니다.
- 이미지 한 장은 4096×4096 픽셀에 해당하는 총 픽셀 수까지, 전체 이미지는 약 6,700만 픽셀까지 불러올 수 있습니다. 설정에 따라 추가 처리량 제한이 적용될 수 있습니다.
- 작업 기록 저장은 기본적으로 꺼져 있습니다. 저장을 켜면 파일명, 변환 설정, 결과 이미지가 현재 브라우저의 IndexedDB에 저장됩니다.
- 공용 기기에서는 작업 기록 저장을 켜지 않는 것을 권장합니다.
- 원본 규격 유지 모드의 외곽선은 프레임 내부에만 그려지며, 프레임 바깥으로 확장되지 않습니다. PNG의 DPI·색상 프로필 같은 부가 메타데이터는 보존하지 않습니다.

## 개발자를 위한 실행 및 점검

프로젝트 디렉터리에서 정적 HTTP 서버를 실행합니다.

```sh
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173/pixelate_studio.html`을 엽니다.

변경 후에는 보안 검사를 실행합니다.

```sh
node scripts/security-check.mjs
node scripts/preserve-sheet-check.mjs
node scripts/animation-check.mjs
node scripts/ani001-ui-check.mjs
node scripts/grid-detection-check.mjs
node scripts/grid001-ui-check.mjs
```

애니메이션 검사는 동일 파일명 시트의 정책 메타데이터 분리, 257프레임 초과 시트의 재생 차단·제어 비활성화·프레임 표시 초기화, 정상 시퀀스의 재생 및 닫기 cleanup, 정상+초과 시트 혼합 입력에서 제외 사유 노출을 포함합니다. ANI-001의 상세 검증 결과는 [증거 보고서](./pixelizer-codex-research/evidence/ani-001/README.md)에서 확인할 수 있습니다.

GRID-001은 clean/wobble/photo fixture, alpha topology, confidence gate, margin 계산, manual range, sequence lock, 전체 main-thread chunk 계측, 4M 상한 및 결정성 검사를 포함합니다. 자동 검증 결과와 남은 브라우저 QA는 [GRID-001 증거 보고서](./pixelizer-codex-research/evidence/grid-001/README.md)에서 확인할 수 있습니다.

배포 환경의 보안 헤더와 개인정보 처리 방식은 [SECURITY.md](./SECURITY.md)를 참고하세요. Vercel에서는 `vercel.json`이 루트 경로와 보안 헤더를 설정합니다.
